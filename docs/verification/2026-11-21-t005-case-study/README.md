# T-005 case study screenshots

Evidence for `T-005` on the `design/working-record` branch, captured 2026-11-21
against a production build served by `astro preview`. Nine sections at 320, 768,
and 1280 CSS px in light and dark: 54 JPEGs, one per section and size. The fixed
header, skip link, and chat control are hidden so they do not paint over a tall
element.

| Prefix | Section |
| --- | --- |

| `02-why-*` | three numbered problem records |
| `03-roles-*` | function schedule; seven records, ruled role rows |
| `04-loop-*` | six numbered steps with role and gate labels |
| `05-gates-*` | human-gates table inside its scroll region |
| `06-tiers-*` | permission-tiers table, hard rules, callout |
| `07-evidence-*` | three dated evidence records and the claim callout |
| `08-questions-*` | six ruled question records |
| `09-closing-*` | closing record and the two controls |

What the shots check: the h1 is set at section size; the role count appears in
running text, the facts line, and the schedule, never as a display figure; the
tables scroll inside their region at 320; sections are separated by a 1px rule;
no gradient, glass, pill, uppercase mono label, or shell chrome.
